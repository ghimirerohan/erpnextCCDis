🗓️ Nepali Date Picker Update

Mini English Dates Feature Now Enabled

✅ What's New?

All Nepali BS date pickers in your custom_erp web apps now display mini English dates in the corner of each calendar cell. This makes it easier to reference both Nepali and English dates simultaneously.

Expected Calendar Appearance

Notice the small English date numbers (15, 16, 17...) in the bottom-right corner of each cell

⚙️ Configuration

The date picker is now configured with:

{ dateFormat: 'YYYY-MM-DD', inline: true, // Always show calendar below input miniEnglishDates: true, // ✨ NEW: Show small English dates onSelect: (dateObj) => { ... } }

🧪 Testing Instructions

  1. Hard refresh your browser: Press Ctrl+Shift+R (Windows/Linux) or Cmd+Shift+R (Mac)
  2. Navigate to any app: e.g., http://localhost:8080/home
  3. Click on a date picker input
  4. Verify: Calendar shows Nepali dates with small English dates in corners

✅ What You Should See

  • ✅ Inline calendar opens below the input field
  • ✅ Large Nepali numerals (१, २, ३, ४...)
  • ✅ Small English numbers in bottom-right corner (15, 16, 17, 18...)
  • ✅ Light theme with white background
  • ✅ Smooth animations and hover effects

🚨 Troubleshooting

If mini English dates don't appear:

  1. Clear browser cache completely
  2. Hard refresh: Ctrl+Shift+R
  3. Check browser console for errors (F12 → Console)
  4. Verify in Network tab that library loads (42KB JS file)
  5. Restart dev servers:
    # Stop both servers (Ctrl+C) cd /workspace/development/frappe-bench bench start # In another terminal: cd /workspace/development/frappe-bench/apps/custom_erp yarn dev
